# Портфолио Нодиршоха Косимова (Next.js + Supabase)
**Почему так:** Next.js — сайт быстро открывается и хорошо виден в поиске; Supabase даёт базу, вход и хранилище файлов в одном месте; бесплатных планов Supabase и Vercel хватает для старта.

## Запуск на компьютере
1. Установите Node.js 18+. В папке проекта: `npm install`.
2. Создайте проект на supabase.com → SQL Editor → вставьте и запустите `supabase/schema.sql` (email администратора в первой строке — ваш).
3. `cp .env.example .env.local` и заполните ключи из Supabase → Project Settings → API (service_role — только в `.env.local` и на хостинге, никогда в коде).
4. `npm run dev` → http://localhost:3000

## Вход администратора
Supabase → Authentication → Users → Add user: email `k.nodirshoh1@gmail.com` + надёжный пароль (отключите публичную регистрацию: Authentication → Providers → Email → выключить Sign ups). Вход: `/admin`. Права проверяются в базе (RLS): другой пользователь ничего не сможет изменить.

## Работы
`/admin` → «+ Новый проект»: название, описание, категория, год, обложка, изображения/видео, порядок, «Опубликован», ссылка на Behance. «Изменить» / «Удалить» — в списке. Пока нет опубликованных работ, показаны заглушки с пометкой «Временная заглушка».

## Отзывы
Новые отзывы получают статус «pending» и не видны. В `/admin` → «Отзывы»: Одобрить, Скрыть, Удалить. Защита: скрытое поле-ловушка и лимит 3 отправки в час с одного адреса (хранится только хэш).

## Публикация и домен
1. Загрузите проект в GitHub (`.env.local` не попадёт — он в `.gitignore`).
2. vercel.com → Import → добавьте переменные из `.env.example` → Deploy. Укажите `NEXT_PUBLIC_SITE_URL`.
3. Vercel → Settings → Domains → добавьте домен и пропишите DNS-записи у регистратора.
4. Положите `public/og.png` (1200×630) для превью в соцсетях.
